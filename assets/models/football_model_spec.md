# Football Model Spec (Hytopia)

- Style: Voxel, slightly elongated American football.
- Approx size in world units: 0.6 wide x 0.6 high x 1.0 long.
- Orientation: forward along +Z, laces up on +Y.
- Format: GLB (Blockbench -> GLB export).
- Textures: 16x16 or 32x32, brown leather with white laces and stripes.

Use this spec in Blockbench or Triplo. Export as:
`models/football.glb`
