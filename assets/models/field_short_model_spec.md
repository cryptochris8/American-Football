# Short Field Model Spec

- Shortened American football field with:
  - Hash marks and yard lines.
  - End zone is optional for this mini-game; focus on midfield look.
- Scale so that:
  - QB spawn point at roughly (0, 0, 0).
  - Short targets around z ≈ 10.
  - Medium around z ≈ 20.
  - Deep around z ≈ 30–35.

Export as:
`models/field_short.glb`
